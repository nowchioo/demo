1.  运行

```shell
npm run dev  --module=****  ## module指定运行的模块，默认为main
```

2.  打包

```shell
npm run  build  --module=****  ## module指定打包的模块，默认为main
```

3.  alias

```typescript
{
'@'=>'/src',
'@utils' =>'/src/utils',
'@components'=>'/src/components',
'@stores'=>'/src/stores',
'@modules'=>'/modules',
},
```
